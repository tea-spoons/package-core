# Package Core

Core functionality for other packages.

## Installation

In Unity: **Window > Package Manager > + > Add package from git URL**, then enter:

```
https://github.com/tea-spoons/package-core.git
```

Pin a release by appending a tag, for example `#v1.5.0`.
